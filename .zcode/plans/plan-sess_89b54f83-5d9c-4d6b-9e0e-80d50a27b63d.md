# 把 OUA 完整后端搬到网页端（可访问性 HTTP API）

## 目标
开启「可访问性」后，用浏览器打开 `http://127.0.0.1:8964/`，除了看到 OUA 前端，还能像桌面版一样完成**全部后端操作**：设定/更换安装目录、拉取分支、检测版本、安装/更新/切换分支、本地 ZIP 导入、通知、自更新、各类配置、重置/重启/卸载等。现有 `updatePage.js`/`app.js` 等前端**零改动**。

## 核心思路
- 后端：在 Electron **主进程内**直接起一个 HTTP 服务（不再 spawn 子进程），复用现有 service 层，暴露 `/api/*` JSON 接口镜像 40 个 IPC 操作；用 SSE 推送进度。
- 前端：新增 `apiBridge.js`，浏览器环境（无 `window.electronAPI`）时用 `fetch` + SSE 造一个**同构的 `window.electronAPI`**，让现有渲染层代码照常运行。

---

## 一、后端：新建 `main/services/accessServerService.js`
一个主进程内的 Node HTTP 服务，能力：

1. **静态文件**：托管 `renderer/`（目录穿越防护、MIME、`/`→index.html）。
2. **REST API**：`POST /api/invoke/<channel>`，body `{ args: [...] }`，内部用一张 channel→handler 注册表派发，直接调用现有 service（configService/versionService/updateService/folderService/selfUpdateService/notificationService/appService）与 Electron 模块（dialog/shell/app）。返回 `{ ok:true, data }` 或 `{ ok:false, error }`。
   - 覆盖全部 40 个 channel（fileIPC/updateIPC/dialogIPC/main.js 内联的），channel 名与 preload 里的 IPC 名一致。
   - 进度型 handler（first-install/force-overwrite/update-app/switch-branch/import-local-zip/self-update-download）额外接收 progress 回调，广播到 SSE。
3. **上传**：`POST /api/upload`（multipart）→ 保存到临时目录 → 返回 `{ ok:true, path }`，供浏览器 ZIP 导入用。
4. **SSE**：`GET /api/events` → 推送 `progress`（channel/percent/message）与 `http-server-status-change`。
5. **鉴权**：请求来源为 127.0.0.1/::1/localhost 时放行；否则要求 `?token=` 或 `Authorization: Bearer` 匹配 `config.accessibility.token`。静态页放开，`/api/*` 与 `/api/events` 受控。

## 二、改造 `main/services/httpServerService.js`
- 保留对外接口 `qiDong/guanBi/huoQuZhuangTai/onStatusChange/offStatusChange`，`main.js` 的 IPC 处理器与启停逻辑不动。
- `qiDong` 改为启动/重启 `accessServerService`（在进程内 `listen`），不再 `spawn`；`guanBi` 关闭 HTTP 服务。
- 删除子进程文件 `main/services/webServer.js`（静态 + `/proxy` 逻辑并入 accessServerService；`/proxy` 是 OOOInterface 的代理后端，非 OUA，予以移除）。

## 三、配置：`main/services/configService.js`
- `accessibility` 增加 `token` 字段（默认 null）。启用时若无 token 则生成随机 token 并保存。
- `get/setAccessibilityConfig` 同步携带 token。

## 四、前端桥：新建 `renderer/js/apiBridge.js`
- 若 `window.electronAPI` 已存在（Electron）→ 直接返回，不覆盖。
- 否则构造同构 `window.electronAPI`：
  - `platform`（navigator 推断）、`isDev=false`、`path.join/sep`（JS 实现，复制 preload 的 joinPath）。
  - 各 namespace 方法 → `fetch('/api/invoke/<channel>', {args})`。
  - 事件订阅 `update.onUpdateProgress / selfUpdate.onProgress / httpServer.onStatusChange` → 共享一个 `EventSource('/api/events')`，按 channel 分发，返回取消订阅函数。
  - `dialog.selectFolder`：优先 `window.showDirectoryPicker`；拿不到可用路径时回退——弹出轻量输入框填绝对路径，并提供「调用本机原生选择框」按钮（触发 `/api/invoke/select-folder` 主进程原生目录框）。
  - `dialog.selectZipFile`：动态建 `<input type=file accept=.zip>` → `/api/upload` → 返回临时路径。
  - `getFilePath(file)`：异步上传该文件到 `/api/upload` 返回临时路径（`ui.js` 已 `await` 它，拖拽导入无需改动）。

## 五、`renderer/index.html`
- 在 `version.js` 之后、`dialog.js` 之前引入 `<script src="js/apiBridge.js"></script>`。
- 可访问性面板增加 token 展示 + 网页访问地址（含 `?token=`）+ 复制/重新生成按钮。

## 六、`renderer/js/settingsPage.js` + `renderer/css/components.css`
- 填充并展示 token 与访问 URL；「重新生成」调用 setAccessibilityConfig 换新 token。
- 少量样式（token 只读框、按钮）。

## 七、验证
1. 桌面版 Electron 功能回归：IPC 路径不变，前端走原 preload，行为不变。
2. 浏览器版：`http://127.0.0.1:8964/` 打开 Aa/Bb/Cc 面板，安装目录显示、分支切换、版本检测、安装/更新进度条、ZIP 上传导入、通知加载均可用。
3. 鉴权：局域网 IP 访问 `/api/*` 无 token 返回 401，带 token 放行；本机 127.0.0.1 免 token。
4. 外部访问开关 + 自更新/重置/重启/卸载接口可正常触发。

## 说明与风险
- 「本机原生选择框」在局域网远端设备上会弹在运行 OUA 的主机上（而非访问者设备），这是跨设备浏览器无法拿到宿主绝对路径的固有限制，已通过「路径手动输入」兜底。
- 删除 webServer.js 会移除之前的 `/proxy` CORS 转发（OOOInterface 后端），按你「我要的是 OUA」的要求处理。
- 本次为架构级改动，我会分后端、前端桥、UI 三步实现，每步做语法与集成验证。
